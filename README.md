# Keos Technology — website redesign concepts

Two redesign concepts for [keostechnology.com](https://www.keostechnology.com/) (Keos Technology, LLC — expert Splunk consulting).

| Concept | Folder | Live preview |
|---|---|---|
| **Vivid** — "Cabinet of Curiosities": scattered data snaps into an actionable dashboard as you scroll | [`design-vivid/`](design-vivid/) | https://keos-technology-vivid.netlify.app |
| **Cyber / SOC** — security-operations console that parses raw events into notable detections | [`design-cyber/`](design-cyber/) | https://keos-technology-cyber.netlify.app |

Both are static sites (HTML/CSS/JS, no build step), fully responsive, respect `prefers-reduced-motion`, and ship Netlify Forms contact forms plus security headers in `netlify.toml`.

All copy comes from the current site. The "KEOS TECHNOLOGY" wordmark is a placeholder until the official logo is supplied. Dashboard and log visuals are illustrative sample data.
